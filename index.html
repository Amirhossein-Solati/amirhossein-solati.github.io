04 / Applied work

Selected projects

A selection of research and implementation projects across wireless systems, optimization, machine learning, and antenna design.

PROJECT / 01MATLAB · CVX

UAV Selection & Trajectory Optimization

Formulated a non-convex optimization problem for joint UAV selection and 3D trajectory planning to maximize energy efficiency in multi-UAV networks, solved using Successive Convex Approximation.

PROJECT / 02PYTHON · SIONNA · TENSORFLOW

End-to-End Learning for Physical Layer Systems

Used Sionna's autoencoder framework to model communication systems as end-to-end neural networks and evaluate neural signal detection and probabilistic shaping.

PROJECT / 03PYTHON

Performance Analysis of MIMO Coding Schemes

Simulated Alamouti, orthogonal, and non-orthogonal space-time block coding schemes and analyzed BER performance over Rayleigh fading channels.

PROJECT / 04MATLAB

Implementation of Applied Optimization Algorithms

Implemented gradient descent and heuristic search methods, including Genetic Algorithm and Ant Colony Optimization, for complex optimization problems.

PROJECT / 05HFSS · CST STUDIO

Design & Simulation of UWB Microstrip Antenna

Designed a compact ultra-wideband antenna with notch filtering for interference suppression and validated return loss and radiation characteristics through full-wave simulation.
